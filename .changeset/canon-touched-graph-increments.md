feat(canon): the history↔code semantic join — session→file `touched` edges, graphify auto-detect, and cross-project routing.

- **Touched edges**: `canonGraph` now scans canon session content (streaming, parts-aware; incremental via `~/.canon/touched-cache.json` — 2,570 sessions ≈ 20s first scan, ~1s cached) extracting the file paths each session's tool calls touched, and emits `sess → file` `touched` edges (EXTRACTED / 1.0, weight = touch count, provenance = the canon session path). Targets prefer the code half's file-level node, else a lightweight `file:` node — no touch is dropped. Default on; `--no-touched` to skip.
- **graphify auto-detect (mode A automatic)**: each project's `graphify-out/graph.json` (from `graphify update <root>`) is folded into that project's graph automatically; `--merge-graph` remains as explicit override. Merged graphs record `graph.code_half` provenance.
- **Cross-project routing**: touched edges route to the *owning* project by longest-root-match (project roots nest); a session homed elsewhere gets a marked foreign `sess:` node (`foreign_home`) — cross-project work is first-class. Dual-lineage sessions (pull = branch) are handled correctly: the touched index is keyed by session path (uuids repeat across lineages) and same-uuid edges dedupe at max weight.
- **Portability**: the project↔session map is now fully environment-derived (`$HOME` + filesystem-guided decode of Claude Code's path encoding) with user overrides at `<store>/projects/ROOTS.json` (`roots` / `claudeDirs` / `cortexLabels`, scaffolded by `canon init`) — no hardcoded roots; foreign-machine session dirs degrade to override-needed entries instead of misbehaving.
- **No-churn automation**: graph builds are content-hash guarded (`built_at_commit` refreshes only when the graph body actually changed), making `canon graph` safe on any cron/hook cadence.
- **Touched tier 3**: Bash command-string parsing (redirections, `tee`, `sed -i`, `cp`/`mv`, `touch`, direct `cat`/`head`/`tail` reads) contributes INFERRED-confidence touched edges — heredoc bodies and quoted inline code are excluded, relative paths resolve against the recorded cwd, and structured evidence always wins.
- **Declarative capture sources**: `canon sync` reads `<store>/HARNESSES.json` (`{harnesses: {label: {exts, roots}}}`, `~`-expansion, labeled multi-roots) — adding a harness to capture is configuration, not code.
- **grok-build adapter (v1.1)**: grok-build sessions translate to the canonical line — `chat_history.jsonl` becomes full canonical Messages (xAI reasoning → thinking blocks, OpenAI `tool_calls` → `tool_use`, per-message model provenance; deterministic ids, uuidv7-derived timestamps), `prompt_history` → user Messages, events telemetry → sidecars. Session discovery understands dir-per-session envelopes.
- **gemini-cli adapter (v1)**: current-format `chats/*.jsonl` sessions (event-sourced log with supersede-by-id updates) translate to full canonical Messages — thoughts → thinking blocks, embedded `toolCalls`+results → paired `tool_use`/`tool_result`, per-message model/usage provenance; wire-duplicate `functionResponse` records sidecar. All four captured harnesses now translate.
